# QQ-AI-BOT

一个开箱即用的 QQ 群聊 AI 机器人：**双击一个快捷方式就能跑**——自动建虚拟环境、装依赖、下载协议端，网页里填好 QQ 号和 API Key，扫码上线。

> 📖 **完整部署文档、配置说明与踩坑记录见 [程序/README.md](程序/README.md)**

## 功能一览

| 功能 | 说明 |
|---|---|
| 💬 群聊 / 私聊对话 | @机器人即可，带说话人识别与多轮上下文（防串人） |
| 📁 群文件内容检索 | 不只搜文件名——txt / md / docx / PDF **内容**也能搜，本地分块索引 + RAG |
| 🗂 群文件 / 群相册检索 | 问「群里有没有 XX」，直接告诉你文件在哪个文件夹 |
| ⭐ 群精华消息检索 | 问「精华里有没有讲 XX 的」，说清是哪位群友发的 |
| 👥 群成员识别 | 「@小a」和正文里的「小a」都认得出是谁，连群头衔一起答 |
| 🖼 识图 | 发图能看图说话（需模型支持多模态） |
| 🔍 联网搜索 | 带每日额度闸门，按官方真实计费次数扣减，闲聊不联网不花钱 |
| 🎊 入群欢迎 | 用人设口吻自动欢迎，带限流与模板兜底 |
| 🎭 表情包 | 本地目录随机发送，不依赖在线图库 |
| 🛡 防幻觉铁律 | 事实约束由代码强制附加，人设怎么改都覆盖不掉 |

## 架构

```
QQ 服务器
    ↕  NTQQ 协议
NapCat（协议端）── 登录 QQ 号，把 QQ 协议翻译成 OneBot v11
    ↕  反向 WebSocket
NoneBot2（框架）── 收发消息、上下文、限流、工具调用
    ↕  OpenAI 兼容 HTTP
大模型 API ── 任意 OpenAI 兼容接口（MiMo / GLM / 百炼 / Ollama …）
```

本机只做轻活，常驻内存约 150–250 MB，2 核 2G 的小机器甚至树莓派都能跑。

## 三步上手

**Windows**：

1. 装 **Python 3.10+**（勾选 *Add Python to PATH*）
2. 双击 **`程序/启动.bat`**
3. 网页里填 QQ 号 / 模型厂商 / API Key / 人设 → **测试连接** → **开始部署** → 扫码

没有 Python 也没关系：`程序/启动.bat` 会用中文提示并帮你打开下载页；启动器还会自动修复失效的快捷方式。

**macOS**：

1. 装好 **QQ.app**（NapCat 随 QQ.app 一起跑，见 [QQ-AI-Bot-Mac/MACOS-迁移指南.md](QQ-AI-Bot-Mac/MACOS-迁移指南.md)）
2. 双击 **`QQ-AI-Bot-Mac/启动.command`**
3. 同样的网页配置页 → 保存并启动（服务已做会话隔离，关掉终端照常运行）

两版共用同一套插件代码与网页配置页，配置格式一致。

## 目录结构

```
QQ-BOT/
├── 程序/                 # Windows 版
│   ├── README.md         # 📖 详细文档（部署 / 配置 / 原理 / 踩坑）
│   ├── 启动.bat           # 双击入口
│   ├── launcher.py       # 图形化启动器（建 venv / 装依赖 / 下 NapCat / 拉机器人）
│   ├── bot.py            # NoneBot2 入口
│   ├── plugins/ai_chat/  # 全部功能模块
│   ├── web/              # 本地配置网页
│   ├── tests/            # 离线回归测试（不花钱、不碰真 API）
│   └── stickers/         # 表情包目录（放图即用）
└── QQ-AI-Bot-Mac/        # macOS 版（同一套插件，NapCat 跑在 QQ.app 里）
    ├── 启动.command       # 双击入口
    ├── launcher.py       # macOS 适配版启动器（含配置保护：不覆盖已有对接）
    ├── MACOS-迁移指南.md   # 📖 macOS 部署与迁移文档
    └── plugins/ web/ …   # 与 Windows 版同构
```
