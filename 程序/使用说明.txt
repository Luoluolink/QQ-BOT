QQ AI 机器人 · Windows 免安装版使用说明
========================================

【开始使用】
1. 双击 QQBot.exe，会弹出一个终端窗口并自动打开浏览器配置页
   （没自动打开就手动访问 http://127.0.0.1:8899）
2. 在网页里填：QQ 号 / 模型接口地址 / API Key / 模型名称 / 机器人名字 / 人设
3. 点「保存并启动」，启动器会自动下载 NapCat 协议端（约 120MB，仅第一次），
   然后弹出两个新窗口：机器人核心 + NapCat
4. 在自动打开的 NapCat 页面里用手机 QQ 扫码登录，把机器人拉进群就能用了

【不需要安装的东西】
- Python（已内置在 exe 里）
- 任何依赖库（已内置）

【仍然需要的东西】
- 一个大模型的 API Key（OpenAI 兼容接口均可：官方 / 中转 / 本地 Ollama）
- QQ 客户端：扫码登录的那个号就是机器人本体，
  注意 QQ 电脑客户端和机器人不能同时登录同一个号

【常见操作】
- 改配置：编辑 .env 文件（每一项什么意思见 .env.example），改完重新双击 QQBot.exe
- 改人设：重新跑一遍 QQBot.exe，在网页里改
- 生图功能：本机装好 ComfyUI 后，把 .env 里 AI_IMAGE_ENABLED 改成 true
- 关闭：直接关掉各个窗口即可；下次双击 QQBot.exe 重新启动

【文件夹说明】
- QQBot.exe / _internal\   程序本体（别动）
- bot.py / plugins\        机器人代码（懂 Python 可以自己改）
- web\                     配置页网页
- .env                     第一次启动后自动生成，你的配置和 Key 都在这里
- napcat\                  第一次启动后自动下载的协议端

【注意事项】
- 本工具基于 NapCat 协议端实现，属第三方非官方方案，理论上有封号风险，
  建议用小号
- 整个文件夹可以随便移动/拷贝到别的电脑，快捷方式会自动重建
